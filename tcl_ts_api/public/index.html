REST API

API นี้ห่อ TCL Home auth + AWS IoT shadow ไว้เป็น HTTP ธรรมดา — ใช้จาก curl, Home Assistant, Node-RED หรือ automation อื่นได้

GET /api/devices

รายการอุปกรณ์ที่ตั้งค่าไว้ใน config.json

curl http://localhost:3100/api/devices
GET /api/ac/status

อ่านสถานะแอร์จาก device shadow — เปิด/ปิด, อุณหภูมิเป้าหมาย, อุณหภูมิห้อง

curl http://localhost:3100/api/ac/status
POST /api/ac/power

เปิดหรือปิดแอร์

curl -X POST http://localhost:3100/api/ac/power \
  -H 'Content-Type: application/json' \
  -d '{"on": true}'
POST /api/ac/temperature

ตั้งอุณหภูมิเป้าหมาย — ส่ง value (ค่าเต็ม) หรือ delta (+/- 1)

# ตั้งเป็น 25°C
curl -X POST http://localhost:3100/api/ac/temperature \
  -H 'Content-Type: application/json' \
  -d '{"value": 25}'

# ลด 1 องศา
curl -X POST http://localhost:3100/api/ac/temperature \
  -H 'Content-Type: application/json' \
  -d '{"delta": -1}'
GET /health

Health check สำหรับ Docker / monitoring

curl http://localhost:3100/health
หมายเหตุ: session login เก็บอัตโนมัติใน session.json — ไม่ต้องส่ง token เองทุก request
